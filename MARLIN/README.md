# MARLIN project source

This folder contains the complete curated MARLIN project tree as a ZIP archive. Download [MARLIN_Project_Source.zip](MARLIN_Project_Source.zip) and extract it at the repository root to restore the working folder structure, source code, configurations, documentation, selected public-data records, and current v4 outputs.

The archive excludes temporary environments, downloaded jellyfish image files, and the large raw-data package. Source links and retrieval notes are included in the extracted project.

The v4 output is a conditional screening simulation, not a field-performance claim or proof of 95% capture. Its capture and flow assumptions remain uncalibrated; see `simulation/v4/PHYSICS_REVIEW.md` after extraction.

The standalone v4 simulation archive is also available at [MARLIN_Simulation_v4.zip](../MARLIN_Simulation_v4.zip).
