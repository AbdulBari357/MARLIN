# MARLIN

**Marine Adaptive Response and Lifecycle Intervention Network**

MARLIN is a proposed, two-layer jellyfish interception and recovery concept for protecting a coastal power-plant intake. This repository holds the proposal deck and the current simulation package.

## Start here

- [Proposal deck (PDF)](MARLIN_ENEC_Proposal.pdf) · [editable PowerPoint](MARLIN_ENEC_Proposal.pptx)
- [Project overview](MARLIN/README.md)
- [Complete curated project source tree](MARLIN/MARLIN_Project_Source.zip)
- [v4 simulation package](MARLIN_Simulation_v4.zip)

Extract the project source ZIP at the repository root to restore the browsable `MARLIN/` folder structure and run the documented workflows. From the repository root, with Python 3.10 or newer, the v4 runner is `python MARLIN/simulation/v4/run_scenarios.py`.

The v4 package is a conditional research model, **not** a prediction of ENEC site performance or proof of 95% capture. It uses uncalibrated contact, geometry, flow, collection, and transport assumptions. It does not establish animal survival, bycatch outcomes, operational safety, or regulatory approval. Read the physics review and run report before interpreting percentages.

The public repository includes source code, configurations, documentation, selected processed public forcing tables, and the latest v4 outputs. Temporary files, virtual environments, downloaded image files, and the large raw-data bundle are excluded; download instructions and provenance are documented in the source ZIP.
